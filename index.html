Como Jogar

Preparação

Uma sala é criada com um Tema específico. Quando a partida começa, 3 jogadores recebem a Palavra Secreta, enquanto o Impostor vê apenas o Tema

Rodadas

O jogo dura 3 rodadas, em cada rodada os jogadores devem digitar uma única palavra relacionada à Palavra Secreta

Objetivo

Seja claro o suficiente para que seus aliados saibam que você é confiável, mas vago o bastante para que o Impostor não consiga adivinhar a palavra

O Objetivo do Impostor

Tente se misturar! Use o Tema, exibido no canto superior esquerdo, para fingir que sabe a palavra e passar pelas rodadas

Pular para a Votação

Viu alguém agindo de forma suspeita ou dizendo algo totalmente fora do tema? Use o botão "Poupa-Tempo" para ir direto para a fase de votação

O Veredito

Após 3 rodadas compare as respostas. Analise quem foi inconsistente e vote para eliminar o Impostor
