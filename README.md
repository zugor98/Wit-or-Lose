### Como jogar


O jogo começa com uma palavra. Na sua vez, **troque uma letra** para formar uma nova palavra válida e **passe a vez** para o próximo jogador. E assim a partida segue.

> **A regra de ouro:** só vale mudar **uma letra por jogada**. Se a palavra não existir, a jogada não vale.

### 🕹️ Modos de jogo

| | 🏁 Corrida | ⏱️ Sobrevivência |
|---|---|---|
| **Como funciona** | A partida tem uma palavra inicial e uma final. Os jogadores se revezam trocando letras para se aproximar do destino. | Um timer de **30 segundos** corre contra o jogador da vez. |
| **O risco** | Perder a vez para quem chegar antes. | Se o tempo acabar sem resposta, o jogador é **eliminado** e o resto do time continua na partida. |
| **O objetivo** | Seja o primeiro a chegar à palavra final. | Seja o último a ficar de pé. |

### ⚙️ Regras da partida

Antes de começar, escolha as regras no menu:

- **Só trocar letra**
- **Tamanho fixo**
- **Não repetir palavras**

### 🏆 A vitória

Vence quem cumprir o objetivo do modo escolhido.
